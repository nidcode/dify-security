# 4. ユーザーアクセスの追加・削除

「誰がどの Dify インスタンス(チーム)に入れるか」を変更する手順。異動・入社・退職時に使う。

置き換え: `<TEAM>` `<GATEWAY_DOMAIN>` `<GATEWAY_HOST>` `<REPO_DIR>`。

チームごとに、以下の**どちらの方式で運用しているか**が「Difyインスタンスの追加と削除」の
手順書(追加③)の時点で決まっている。不明な場合はベンダーに確認する。

## A. EntraID (Azure AD) 側で管理している場合 (通常運用・推奨)

**このリポジトリ側の操作は不要。** Azure ポータル側だけで完結する:

- **追加**: 対象ユーザーを、そのチームに割り当てられている EntraID の App ロール または
  セキュリティグループに追加する。
- **削除**: 同じ App ロール/グループから外す。

反映は**次回ログイン時**(Keycloakが毎回EntraID側の所属を見て自動的に権限を合わせるため)。
即時に反映させたい場合は該当ユーザーに一度ログアウト/再ログインしてもらう。

## B. Keycloakグループへの個別追加 (例外・暫定運用)

EntraID側のグループ/ロール割り当てが使えない場合や、検証用に特定ユーザーだけ通したい場合。

### 追加

1. `https://auth.<GATEWAY_DOMAIN>/admin/` に管理者でログイン
2. 対象realm → **Users** → 対象ユーザーを検索 (いなければ先にログインさせてEntraID経由で
   自動作成させるか、Add userで作成)
3. **Groups** タブ → **Join Group** → `/aiop-<TEAM>` (接頭辞は`.env`の`KEYCLOAK_GROUP_PREFIX`)
   を選択

### 削除

同じ画面の **Groups** タブ → `/aiop-<TEAM>` の **Leave**。

## 確認

対象ユーザーに `https://<TEAM>.<GATEWAY_DOMAIN>` へアクセスしてもらい、通る/弾かれる(403)
ことを確認する。
