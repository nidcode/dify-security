### A-3. 共通関数の読み込み

以下をシェルに貼り付ける（このセッション中は再入力不要）。

```bash
BENCH() {
  local ds=$1 name=$2; shift 2
  docker run --rm --network host -e HF_HUB_OFFLINE=1 \
    -v "$PWD/bench:/bench" -v "<VLLM_MODELS_DIR>:/root/.cache/huggingface:ro" \
    <VLLM_BENCH_IMAGE> \
    vllm bench serve \
      --backend openai-chat --base-url http://localhost:<VLLM_PORT> \
      --endpoint /v1/chat/completions \
      --model <VLLM_MODEL_ID> --served-model-name <VLLM_SERVED_MODEL_NAME> \
      --dataset-name custom --dataset-path "/bench/datasets/h100/${ds}" \
      --custom-output-len -1 --skip-chat-template --disable-shuffle --no-oversample \
      --num-warmups 3 --disable-tqdm \
      --percentile-metrics ttft,tpot,itl,e2el --metric-percentiles 50,90,99 \
      --save-result --save-detailed \
      --result-dir /bench/results --result-filename "${name}.json" "$@"
}
```

### B-2. Dify・LiteLLM側の監視スクリプトを配置（Dify VM / LiteLLM VM で実行、初回のみ）

`vmstat`はデフォルトでは時刻が付かないため、**`-t`でタイムスタンプ付き出力にする**。
測定ステップ（B-3〜B-5）ごとに監視を開始・停止し、ログファイル名にステップ名を入れる。
PIDをファイルに保存し、別セッションからでも確実に停止できるようにする。

**Dify VM・LiteLLM VM の両方に配置：**

```bash
cat > monitor.sh <<'EOF'
#!/bin/bash
# 使い方: ./monitor.sh start <ステップ名> | ./monitor.sh stop
case "$1" in
  start)
    LABEL="$2"
    vmstat -t 1 > "vmstat_${LABEL}.log" &
    echo $! > vmstat.pid
    ( echo "timestamp,container,cpu_perc,mem_usage,mem_limit,mem_perc"
      while true; do
        TS=$(date +%s)
        docker stats --no-stream --format '{{.Name}},{{.CPUPerc}},{{.MemUsage}},{{.MemPerc}}' \
          | awk -F',' -v ts="$TS" '{split($3,m," / ");gsub("%","",$2);gsub("%","",$4);print ts","$1","$2","m[1]","m[2]","$4}'
        sleep 1
      done > "docker_stats_${LABEL}.csv" ) &
    echo $! > dockerstats.pid
    echo "監視開始: ${LABEL}"
    ;;
  stop)
    kill "$(cat vmstat.pid)" "$(cat dockerstats.pid)" 2>/dev/null
    rm -f vmstat.pid dockerstats.pid
    echo "監視停止"
    ;;
esac
EOF
chmod +x monitor.sh
```
